# logger 模块文档

> 本目录是 `logger` 模块的完整文档集合。

## 概述

`logger` 提供带级别、调用点、trace 链路字段的结构化日志：text（人读）与 JSON（机器采集）双格式，控制台 + 文件双输出，按天滚动 + 过期清理。默认实例开箱即用，也支持自定义实例与全局替换；可选挂载 OTLP 导出，与 trace 同后端互跳。
