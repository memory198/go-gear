## 状态定义

- 🟡 **调研中**：收集信息、评估候选方案
- 🔵 **实现中**：方案已定，正在编码
- 🧪 **测试中**：实现完成，验证阶段
- ✅ **已完成**：工作收尾，结论已沉淀
- ⏸ **已搁置**：暂停，后续可能继续
- ❌ **已放弃**：不再推进（方案文档中记录放弃原因）

## 新增方案文档约定

1. **文件名**：`开始日期-方案概括.md`（如 `2026-09-02-日志链路打通方案.md`）——以日志（日期）开头，后接方案概括
2. **文档首行**标注创建日期，内容围绕方案组织：目标 / 背景 / 方案设计 / 开发进度 / 结论，**不写流水账**
3. **开发进度**直接追加到方案文档内的进度小节（含日期），跨多天开发的方案在同一文档内持续更新
4. 方案状态变更时，同步更新本表的"状态"与"最近更新"
